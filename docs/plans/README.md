# Планы миграций

Один файл на миграцию, пишется до кода и дополняется после. Структура каждого: разделы ТЗ, функции
и их проверки по порядку с кодами ошибок, строки ledger по переходам, тесты, затем "Решения" -
вопросы, на которые ТЗ не отвечало, с принятым ответом и датой, и "Выяснилось по ходу" - баги и
ограничения, найденные при реализации.

Читать, когда непонятно, почему код устроен именно так: ТЗ говорит "что", планы - "почему именно так".
Новая миграция = новый файл `00NN_<name>.md` по тому же шаблону.
